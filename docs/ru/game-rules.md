# Правила игры

> 🇬🇧 English original: [`../game-rules.md`](../game-rules.md)

## Цикл

```
ЗАКАЗ → ПОДНОС (7 букв) → собрать БЛЮДО (слово) → подать → очки → следующий заказ
```

**Раунд** закрывается, когда каждый шеф подал `ROUND_DISHES = 3` блюда
(пропуск заказа считается прогрессом, но сбрасывает комбо). Матч — это
`rounds_total` раундов (по умолчанию 3).

## Заказы (билеты гостей)

| Вид | Требование |
|---|---|
| `SINGLE_WORD` | любое валидное блюдо |
| `MIN_LENGTH` | ≥ N букв (N растёт со сложностью) |
| `CONTAINS_LETTER` | обязана быть конкретная буква |
| `THEME` | слово из тематического меню (street food, bakery, sushi, space, cyber, ancient, night market) |
| `STREAK` | 2–3 разных блюда подряд внутри одного билета |
| `SPEED` | жёсткий таймер |

Каждый заказ **разрешим по построению**: поднос собирается вокруг опорного
слова, которое уже удовлетворяет ограничению.

## Скоринг

```
score = (base + rarity) × combo × heat × spice × kitchen × flavor × speed × prep × secret
```

* `base = len² × 10` (+ бонусы кухни за гласные/короткие/редкие слова)
* `rarity` = Σ редкости букв (J/Q/X/Z = 3, K/V/W/B = 2, остальные 1) × 4
* **combo** ×(1 + 0.25·combo), потолок ×4
* **heat** ×(1 + 0.08·heat)
* **spice** ×2, когда заряжена (заряды капают каждые 3 комбо)
* **flavor** ×1.5 совпадение / ×1.0 нейтрально / ×0.85 конфликт (см. Вкусовые профили)
* **speed** ×1.2 аль денте (первые 50 % таймера) / ×0.9 пережарено (последние 25 %)
* **prep** ×(1 + 0.1·токены заготовок), максимум 3 токена
* **secret** ×1.5, когда скрытая цель достигнута

Ошибки: комбо сбрасывается (Древняя кухня: −1 вместо сброса), жар −2 (ожог от
приправы: −3, комбо в 0). Полночная кухня никогда не теряет жар.

## Вкусовые профили (оригинальная механика)

`flavor_of(word)`: редкие буквы → **умами**; удвоенная буква → **насыщенное**;
оканчивается на y/o → **кисленькое**; много гласных → **сладкое**; много
согласных → **солёное**; иначе **классика**. Гость «хочет» один вкус на билет.

## Mise en place (оригинальная механика)

Отправьте слово из 2–3 букв как **PREP**: +2 очка за букву, комбо не тронуто,
один токен заготовки в банк (максимум 3), усиливающий следующее блюдо.

## Секретное меню (оригинальная механика)

~25 % заказов прячут цель: `min_length_5`, `two_vowels`, `three_consonants`,
`has_double`, `ends_vowel`, `no_rare_letters`. Успех → +50 %, и секрет
раскрывается.

## Золотые ингредиенты

Редкие/нечастые буквы в успешных блюдах чеканят золотые звёзды. Траты:
`patience` (1⭐ → +15 с), `restock` (3⭐ → замена ингредиента),
`boost` (2⭐ → ×1.5 на следующее блюдо). В Хаос-кухне 1⭐ звонит в 🔔 колокол
(хаос-событие против лидера).

## Кухни (прогрессия)

| Кухня | XP разблокировки | Правило дома |
|---|---|---|
| Уличная кухня | 0 | честные буквы |
| Пекарня | 2 000 | рынок гласных; сладкие слова в почёте |
| Суши-бар | 6 000 | короткие блюда дают больше |
| Космическая кухня | 14 000 | пустота подкидывает дикие буквы |
| Кибер-кухня | 26 000 | глитч-буквы (редкие ×тяжелее) |
| Древняя кухня | 44 000 | щит комбо при ошибках |
| Полночная кухня | 70 000 | жар никогда не остывает |

## Мультиплеер

* **QUICK COOK** — 2–8 шефов, одинаковые заказы и подносы; побеждает тот, у
  кого больше очков.
* **CHAOS KITCHEN** — разные заказы; каждый раунд после первого открывается
  детерминированным хаос-событием: `STEAL_INGREDIENT`, `BURN_TIMER`,
  `SPICE_STORM`, `INGREDIENT_SWAP`, `DOUBLE_ORDER`. 🔔 колокол вызывает одно
  немедленно.

Никакого pay-to-win: покупаемой силы нет ни в каком виде.

## Шпаргалка

* пропустите заказ, который кажется нерешаемым (`SKIP`) — комбо сбросится,
  придёт свежий билет;
* берегите комбо, копите заготовки, затем — большое блюдо с приправой на
  высоком жаре;
* следите за желанием вкуса — оно стоит ×1.5.
