# Тестирование

> 🇬🇧 English original: [`../testing.md`](../testing.md)

Запуск всего:

```bash
./scripts/run_tests.sh
# = pytest + приёмка Prolepsis (29 проверок) + проверка сборки фронтенда
```

## Гейт детерминизма

Критический контракт проверяется напрямую:

```
тот же вход → то же исполнение → тот же канонический результат → тот же дайджест
```

(`TestDeterminism::test_same_input_same_digest` — два прогона, разные
`execution_id`, идентичные дайджесты и идентичные ссылки CAS.)

## Приёмка и смоук

* `python3 scripts/acceptance_prolepsis.py` — производственная приёмка слоя
  Prolepsis (29 проверок, и в процессе, и через HTTP `agent-serve`).
* `python3 scripts/smoke_test.py http://localhost:8000` — сквозной прогон
  против живого сервера: оболочка → матч → блюдо → анти-чит → завершение →
  вердикт реплея → таблица → аудит → эндпоинты платформы.

## Добавление тестов

Правила игры — в `tests/unit/` против чистого движка; всё, что касается
исполнений, — в `tests/prolepsis/`; всё про читерство — в `tests/anti_cheat/`.
Для слов, решающих заказ, используйте `tests/helpers.py::find_word` — он
сканирует весь словарь.
