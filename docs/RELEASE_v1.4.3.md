# Word Chef v1.4.3

## Mobile visual release

- Исправлена композиция главного экрана на Android.
- Hero-изображение больше не растягивает портрет повара в огромный овал.
- Заголовок кампании закреплён в нижней зоне hero с читаемым градиентом.
- Avatar повара приведён к стабильной круглой форме.
- Исправлена вертикальная компоновка игрового экрана.
- Колесо букв и все буквы лучше помещаются на типовых Android-экранах.
- Уменьшены лишние вертикальные зазоры между кроссвордом, строкой слова и колесом.
- Добавлена отдельная адаптация для экранов до 390 px.
- Android versionCode повышен до 5.
- Frontend/backend/Android metadata синхронизированы на 1.4.3.
